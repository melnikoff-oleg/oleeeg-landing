# Ubersuggest exports

Drop raw exports and screenshots here, unedited. Nothing in this folder is a task list, it is evidence that tasks were derived from.

**Naming:** `YYYY-MM-DD-what-it-is.ext`, for example `2026-08-24-site-audit.csv` or `2026-08-24-keyword-ideas.png`.

**Then:** triage into `../BACKLOG.md` as `U-xx` items. Read the triage note at the bottom of that file first, several of Ubersuggest's standard findings are already handled or are deliberate design decisions on this site.
